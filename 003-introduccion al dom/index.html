Laboratorio 3: Primeros pasos con el DOM

Aprende a conectar JavaScript con HTML. Primero modifica la página sin botones; los eventos se introducen en el ejercicio 08.

  1. 01. HTML y JavaScript conectados — Conocer id, script defer y consola
  2. 02. Seleccionar un elemento — document.querySelector y selectores por id
  3. 03. Leer el texto de HTML — textContent para consultar
  4. 04. Cambiar textos de una página — Asignar textContent
  5. 05. Seleccionar varios elementos — querySelectorAll y for...of
  6. 06. Cambiar estilos sencillos — style y classList
  7. 07. Leer un campo de entrada — input.value
  8. 08. Mi primer botón — addEventListener("click", ...) explicado paso a paso
  9. 09. Botón que lee un input — Combinar click, value y textContent
  10. 10. Mini reto: cambiar una ficha — Integrar selección, texto, estilo y un clic
